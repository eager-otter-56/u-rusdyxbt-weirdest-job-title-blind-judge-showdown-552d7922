# Weirdest Job Title: Blind Judge Showdown

Entry for the make.fun bounty "Weirdest Job Title: Blind Judge Showdown".
`main.py` writes a single job title to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
(default `/output`):

> Professional Mourner for Funerals Nobody Attends

Professional mourners are a real occupation; the twist is the booking
condition — this one is retained exclusively for funerals with no guests,
weeping on behalf of an audience that never showed up.
